# RemoveDuplicateWords
программа на языке java для данного условия: Введена строка из повторяющихся слов. Требуется удалить все слова оставив только 1 в строке: abc abc ab abc ab acs acs → abc ab acs
Запустить программу через "cmd" строчкой: java RemoveDuplicateWords
Далее ввести "abc abc ab abc ab acs acs" для проверки работоспособности кода
должно получится - "abc ab acs"
если всё получилось - код работает корректно
